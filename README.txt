羅雅印刷 網站檔案

【頁面】
index.html                首頁（主視覺為 assets/hero.mp4 影片，自動播放、靜音、循環）
printing-binding.html     印刷及裝訂
material-processing.html  材料加工
about.html                關於羅雅
contact.html              聯絡我們
style.css                 全站樣式
assets/                   圖片、標誌、影片（hero.mp4 16 秒循環、hero-poster.jpg 為影片載入前的預覽圖）
wix-embed.html            只有主視覺的單檔版，可貼進 Wix「嵌入程式碼」

【動畫要看得到，請注意】
1. 解壓縮後，index.html、style.css 與 assets 資料夾必須放在同一層，assets 裡的 hero.mp4 不能少。
2. 在 GitHub 專案裡直接點 index.html 只會看到程式碼，要開啟 Pages 之後用網址瀏覽才會播放。
3. 本機測試：解壓縮後用瀏覽器（建議 Chrome）直接開啟 index.html。
